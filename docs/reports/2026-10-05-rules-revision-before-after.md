## 2. 의도적으로 바꾸지 않은 것

- Rule 46 격리 요건과 "무제한 fallback 금지"는 그대로다. Rule 4-B에 "Rule 46은 완화되지 않는다"를 명시했고, 체크리스트에는 기존 문구를 그대로 게이트로 옮겼다.
- 오케스트레이터 정리는 사용자 전용이고, 포그라운드 표시 스폰과 Snyk At Inception도 마찬가지다. 세 가지 모두 기존 문구 그대로 10개 게이트에 넣었다.
- Rule 49의 "세션 간 전달은 telepty로만"은 그대로다. 바꾼 것은 6항이 릴리스 전체를 막던 부분뿐이다. 격리 워커의 보고 경로가 아직 배선되지 않았다는 문장(#1170/#1136)도 그대로 두었다.
- Rule 37 모호성 게이트는 그대로다. 요청의 의도가 무엇인지는 기술 선택이 아니므로 계속 사용자가 정한다.
- Rule 35 재현 우선과 Rule 4-A 실행 모드 선택 본문은 그대로다. 체크리스트에서 게이트 표시만 뺐다.
- `docs/sawp.md`, `CLAUDE.md`, `docs/templates/dispatch-ref-template.md`, `tooling/instructions/common.md`는 읽고 확인했지만 모순이 없어 바꾸지 않았다.
