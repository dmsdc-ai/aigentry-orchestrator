# 0.2.2 task dispositions (release group `release-1171`)

Planning evidence for `release/0.2.2.json`. Every task in the release group is listed once.

- **shipping**: this release contains changed paths owned by the task, and the scope statement is what those
  changes deliver. It is a slice of the task, not the whole task.
- **non-shipping**: the task owns changed paths, but they do not deliver the task's scope. Typically they are
  modules no shipped entry point calls, or a preparatory change.
- Publishing 0.2.2 closes no task. Every task below stays open and continues into the next release.

Path counts are the owned-path counts from the ownership attribution of `v0.2.1..4e0e788` (the commit
before this file was added). That range has 353 changed paths and every one has an owner. This file, the
manifest `release/0.2.2.json` and the security records under `release/security/0.2.2/` are added after
that commit, belong to task 1171 and are not counted.
